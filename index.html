1 📋

Planung der Lektion Lesson Planning 課程規劃

```

Bevor du auch nur einen Block in Minecraft setzt, muss die didaktische Grundstruktur stehen. Eine gut geplante Lernwelt reduziert Chaos im Unterricht drastisch. Before placing a single block in Minecraft, the pedagogical structure must be in place. A well-planned learning world drastically reduces classroom chaos. 在 Minecraft 中放置第一個方塊之前，教學基礎架構必須先確立。規劃完善的學習世界能大幅減少課堂混亂。

🎯 Lernziele definierenDefining Learning Goals定義學習目標

✅ Gutes LernzielGood Goal好的學習目標

"SuS können die drei Aggregatzustände benennen und je ein Beispiel nennen." "Students can name the three states of matter and give one example each." 「學生能說出物質的三態並各舉一例。」

Messbar · Konkret · Überprüfbar Measurable · Concrete · Verifiable 可測量 · 具體 · 可驗證

❌ Schwaches LernzielWeak Goal模糊的學習目標

"SuS lernen etwas über Wasser und Physik." "Students learn something about water and physics." 「學生學習有關水和物理的知識。」

Zu vage · Nicht überprüfbar Too vague · Not verifiable 太模糊 · 無法驗證

2 ⚙️

Technische Vorbereitung Technical Setup 技術準備

```

Eine korrekt konfigurierte Welt ist das Fundament. Fehleinstellungen führen zu unkontrollierbarem Verhalten der SuS oder kaputten Command-Block-Systemen. A correctly configured world is the foundation. Incorrect settings lead to uncontrollable student behavior or broken command block systems. 正確配置的世界是基礎。錯誤設定會導致學生行為不可控或指令方塊系統損壞。

1

Spielmodus: AbenteuerGame Mode: Adventure遊戲模式：冒險

SuS können Blöcke nur mit speziell erlaubtem Werkzeug abbauen → kein ungewolltes Zerstören.Students can only break blocks with specifically allowed tools → no accidental destruction.學生只能使用特別允許的工具破壞方塊，防止意外破壞。

2

Cheats aktivierenEnable Cheats啟用作弊

Für Command Blocks und NPCs müssen Cheats aktiviert sein.Cheats must be enabled for Command Blocks and NPCs to work.指令方塊和 NPC 需要啟用作弊功能才能運作。

3

Welttyp: SuperflachWorld Type: Superflat世界類型：超平坦

Saubere, leere Fläche ohne Berge oder Höhlen.Clean, empty surface without mountains or caves.乾淨、平整的表面，沒有山脈或洞穴。

4

Schwierigkeit: FriedlichDifficulty: Peaceful難度：和平

Keine feindlichen Mobs → SuS fokussieren sich auf Lerninhalte.No hostile mobs → students focus on learning content.沒有敵對生物，讓學生專注於學習內容。

5

Wetter & Tag/Nacht deaktivierenDisable Weather & Day/Night停用天氣與晝夜循環

Konstante Sichtverhältnisse für alle SuS.Consistent visibility for all students.為所有學生提供一致的視野條件。

4 📊

Scoreboards

Scoreboards sind das Nervensystem deiner Lernwelt — sie tracken Punkte, Status und freigeschaltete Zonen. Scoreboards are the nervous system of your learning world — they track points, status, and unlocked zones. 計分板是你的學習世界的神經系統——追蹤積分、狀態和已解鎖的區域。

```
💻 Scoreboard SetupScoreboard Setup計分板設定
# Scoreboard erstellenCreate scoreboard建立計分板 ``` /scoreboard objectives add Fortschritt dummy “📊 Progress” # AnzeigenDisplay顯示 /scoreboard objectives setdisplay sidebar Fortschritt # +1 Punkt für allepoint for all分給所有人 /scoreboard players add @a Fortschritt 1 # ZurücksetzenReset all重置全部 /scoreboard players set @a Fortschritt 0
```
ℹ️
Nutze separate Scoreboards für Fortschritt, Quiz-Punkte und Zeit — das erleichtert das Debugging erheblich. Use separate scoreboards for progress, quiz points, and time — it makes debugging much easier. 為進度、測驗分數和時間使用獨立計分板，這樣除錯更容易。
```

Export als .mcworld Export as .mcworld 匯出為 .mcworld

Welt verlassenLeave the World離開世界

Hauptmenü → Spielen → Welt-Liste.Main menu → Play → World list.主選單 → 遊玩 → 世界清單。

2

Bearbeiten-MenüEdit Menu編輯選單

Stift ✏️ neben der Welt → "Welt exportieren".Pencil ✏️ next to world → "Export World".點擊世界旁的 ✏️ → 「匯出世界」。

Datei speichernSave File儲存檔案
