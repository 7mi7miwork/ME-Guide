Planung der Lektion

Bevor du auch nur einen Block in Minecraft setzt, muss die didaktische Grundstruktur stehen. Eine gut geplante Lernwelt reduziert Chaos im Unterricht drastisch und erlaubt dir, die Lernprozesse zu beobachten, statt ständig technische Feuer zu löschen.

🎯 Lernziele definieren

Formuliere 3–5 konkrete, messbare Lernziele im Stil von Lehrplänen:

✅ Gutes Lernziel

„SuS können die drei Aggregatzustände benennen und je ein Beispiel nennen."

Messbar · Konkret · Überprüfbar

❌ Schwaches Lernziel

„SuS lernen etwas über Wasser und Physik."

Zu vage · Nicht überprüfbar

📖 Kapitelstruktur planen

Teile die Lernwelt in Module auf. Jedes Modul entspricht einer Zone in der Welt und einem Lernziel:

ModulZone in der WeltLernzielDauer
M0 – IntroSpawn-BereichOrientierung, Regeln~5 min
M1 – GrundlagenZone GrünBasiswissen erarbeiten~15 min
M2 – VertiefungZone BlauZusammenhänge verstehen~15 min
M3 – AnwendungZone RotTransfer & Problemlösung~20 min
M4 – TestTestbereichKompetenzüberprüfung~10 min

2 ⚙️

Technische Vorbereitung der Welt

Eine korrekt konfigurierte Welt ist das Fundament. Fehleinstellungen führen zu unkontrollierbarem Verhalten der SuS oder kaputten Command-Block-Systemen.

🌍 Neue Welt anlegen

1

Spielmodus: Abenteuer oder Überleben?

Für Lernwelten empfohlen: Abenteuer-Modus. SuS können Blöcke nur mit Werkzeug abbauen, das speziell erlaubt ist → kein ungewolltes Zerstören.

2

Cheats / Befehle aktivieren

Für Command Blocks und NPC-Skripte müssen Cheats aktiviert sein. Gehe zu: Welt bearbeiten → Spieloptionen → Cheats: AN

3

Welttyp: Superflach

Wähle Superflache Welt als Typ. Das gibt dir eine saubere, leere Fläche ohne Berge, Höhlen oder zufällige Mobs — ideal zum Bauen.

4

Schwierigkeit: Friedlich

Stelle Friedlich ein, damit keine feindlichen Mobs spawnen und SuS sich auf die Lerninhalte konzentrieren können.

5

Wetter & Tag/Nacht

Deaktiviere Wetterwechsel und den Tages-/Nachtzyklus für konstante Sichtverhältnisse.

👥 Rollen im Überblick

RolleBerechtigungenWann vergeben?
🔴 OperatorAlle Befehle, alle Blöcke, alle RechteNur Lehrkraft
🟡 WorldbuilderKann Barriere-Blöcke platzieren/entfernenLehrkraft-Assistenz
🟢 MemberStandard-SuS: nur erlaubte AktionenAlle SuS
⚪ VisitorNur Beobachten, kein BauenGäste / Demos
💬 Befehle · Rollen vergeben
# Lehrkraft als Operator setzen /op LehrerName # SuS als Member setzen (Standard) /deop SchuelerName # Worldbuilder-Rolle vergeben /worldbuilder AssistenzName
⚠️
Wichtig: Gib niemals SuS Operator-Rechte in einer Unterrichtswelt. Selbst vertrauenswürdige SuS können aus Versehen Command Blocks zerstören oder Scoreboards zurücksetzen.

Eine professionelle Lernwelt folgt einer konsistenten, räumlichen Logik, die SuS intuitiv navigieren können, ohne sich zu verlaufen.

📐 Koordinatensystem & Abstände

🌐 Spawn-Bereich

  • Koordinate: X=0, Z=0, Y=65
  • Größe: ca. 20×20 Blöcke
  • Enthält: Karte, Regeln, NPC

🟢 Zone 1 (Grundlagen)

  • Koordinate: X=+40, Z=0
  • Größe: ca. 30×30 Blöcke
  • Farbcode: Grüne Blöcke/Böden

🔵 Zone 2 (Vertiefung)

  • Koordinate: X=+80, Z=0
  • Größe: ca. 30×30 Blöcke
  • Farbcode: Blaue Blöcke/Böden

🔴 Zone 3 (Anwendung)

  • Koordinate: X=+120, Z=0
  • Größe: ca. 40×40 Blöcke
  • Farbcode: Rote/orangefarbene Böden

🔒 Türen zwischen Zonen

SuS können Zonen nur in der richtigen Reihenfolge betreten. Türen öffnen sich per Command Block, wenn das Scoreboard die nötige Punktzahl zeigt:

🔑 Command Block · Tür öffnen wenn Modul 1 abgeschlossen
# Bedingungs-Block (konditionell) - prüft Score /execute if score @p Fortschritt matches 1.. run setblock ~0 ~1 ~0 air # Oder: Spawnpunkt setzen wenn in Zone angekommen /execute as @a[x=38,y=64,z=-2,dx=4,dy=3,dz=4] run spawnpoint @s 40 65 0
4 📊

Scoreboards für Fortschritt und Aufgaben

Scoreboards sind das Nervensystem deiner Lernwelt. Sie tracken Punkte, Aufgaben-Status, freigeschaltete Zonen und können sogar Zeitlimits messen.

🛠️ Scoreboard anlegen

💻 Scoreboard-Setup · Einmalig beim Start
# Haupt-Fortschritts-Scoreboard erstellen /scoreboard objectives add Fortschritt dummy "📊 Mein Fortschritt" # Aufgaben-Scoreboard (0=offen, 1=erledigt) /scoreboard objectives add Aufgaben dummy "✅ Aufgaben" # Scoreboard auf der Seite anzeigen /scoreboard objectives setdisplay sidebar Fortschritt # Punkte einem Spieler manuell geben (Test) /scoreboard players add @a Fortschritt 1 # Score eines Spielers zurücksetzen /scoreboard players set @a Fortschritt 0 # Score anzeigen lassen (für Lehrkraft) /scoreboard players list

🎯 Fortschrittspunkte automatisch vergeben

Platziere Command Blocks in jeder Zone. Sie prüfen permanent, ob SuS in der Nähe sind und vergeben Punkte:

⚡ Repeat-Command-Block (läuft jede Sekunde)
# Spieler in Zone 1 erkannt → Aufgabe 1 als erledigt markieren /execute as @a[x=30,y=64,z=-15,dx=20,dy=5,dz=20] if score @s Aufgaben1 matches 0 run scoreboard players set @s Aufgaben1 1 # Wenn Aufgabe1=1 UND Aufgabe2=1 → Modul abgeschlossen /execute as @a if score @s Aufgaben1 matches 1 if score @s Aufgaben2 matches 1 run scoreboard players add @s Fortschritt 1
ℹ️
Scoreboard-Struktur empfohlen: Nutze separate Scoreboards für Fortschritt, Quiz-Punkte und Zeit. Mische nicht alles in einem — das macht Debugging viel einfacher.
5 ⚡

Command Blocks: Türen, Bedingungen, Automatisierung

Command Blocks sind die Logik-Schicht deiner Welt. Verstehe die drei Typen, bevor du anfängst:

🟧 Impulse-Block

  • Läuft einmal pro Aktivierung
  • Für: Türen öffnen, Items geben
  • Trigger: Redstone-Signal

🟦 Repeat-Block

  • Läuft dauerhaft (20×/sek.)
  • Für: Score-Checks, Positions-Checks
  • Trigger: Immer aktiv

🟩 Chain-Block

  • Läuft nach dem vorherigen Block
  • Für: Mehrstufige Aktionen
  • Reihenfolge beachten

🚪 Automatische Türen

🚪 Tür öffnen/schließen · Druckplatte → Command Block
# Tür öffnen: Eisentor entfernen (Block ersetzen durch Luft) /setblock 40 65 0 air /setblock 40 66 0 air # Spieler teleportieren wenn Score ausreicht /execute if score @p Fortschritt matches 1.. run tp @p 42 65 0 # Nachricht wenn Score NICHT ausreicht /execute unless score @p Fortschritt matches 1.. run tellraw @p {"text":"🔒 Schließe zuerst Zone 1 ab!","color":"red"}

📢 Nachrichten und Hinweise

💬 Nachrichten an SuS senden
# Einfache Chatnachricht an alle /say Willkommen in Zone 2! Lies das Schild links. # Formatierte Nachricht (JSON) nur an Spieler in der Nähe /tellraw @a[r=10] {"text":"✅ Aufgabe 1 erledigt! +1 Punkt","color":"green","bold":true} # Titel-Einblendung (groß im Bildschirmzentrum) /title @a title {"text":"🏆 Modul abgeschlossen!","color":"gold"} /title @a subtitle {"text":"Weiter zu Zone 2","color":"white"}

🎒 Items vergeben

📦 Items an SuS geben
# Buch als Aufgabenblatt geben /give @p written_book 1 0 {"title":"Aufgabenblatt M1","author":"Frau Muster", "pages":["Lies die drei Schilder und beantworte..."]} # Werkzeug mit eingeschränkter Nutzung /give @p wooden_pickaxe 1 0 {"CanDestroy":["stone","dirt"]}
💡
Tipp: Platziere alle Command Blocks unter der Erde (Y = 10–50), damit SuS sie weder sehen noch versehentlich zerstören können.
6 🤖

NPCs: Aufgaben, Hinweise und Interaktion

NPCs (Non-Player Characters) sind die virtuellen Lehrassistenten deiner Welt. Sie können Aufgaben erklären, Hinweise geben, Punkte vergeben und sogar Befehle ausführen.

👾 NPC erstellen und konfigurieren

🧍 NPC spawnen
# NPC an aktueller Position spawnen /summon npc ~ ~ ~ "Prof. Block" # NPC an bestimmten Koordinaten spawnen /summon npc 42 65 5 "Tutor Steini"

Klicke auf den NPC, um das NPC-Menü zu öffnen. Dort kannst du einstellen:

💬 Dialog-Text

Schreibe erklärende Texte, Aufgabenbeschreibungen oder Hinweise. Unterstützt Zeilenumbrüche mit \n.

🔘 Schaltflächen

Bis zu 6 Schaltflächen pro NPC, jede kann einen Befehl ausführen: URL öffnen, Befehl im Hintergrund, NPC schließen.

🎨 Aussehen

Wähle Skin aus der Bibliothek oder lade einen eigenen hoch. Name über dem NPC ist sichtbar.

📋 NPC-Aufgaben-System

Beispiel: NPC gibt Aufgabe, prüft Lösung via Befehl:

📝 NPC-Konfiguration: "Quiz-NPC Zone 1"

Dialog-Text:

Hallo! Ich bin dein Aufgaben-NPC.
Deine Aufgabe: Finde die 3 roten Schilder in dieser Zone
und merke dir, was drauf steht!

Wenn du alle 3 gefunden hast, klicke auf "Fertig"!

Schaltfläche "Fertig" → Befehl:

/scoreboard players set @initiator Aufgaben1 1
/title @initiator title {"text":"✅ Super!","color":"green"}
/scoreboard players add @initiator Fortschritt 1

7 🛡️

Absicherung von Bereichen

Ohne klare Grenzen werden SuS über kurz oder lang in ungewollte Bereiche gelangen — oder die Struktur zerstören. Nutze alle verfügbaren Mechanismen zur Absicherung.

🧱 Barriere-Blöcke

Barriere-Blöcke sind unsichtbar für SuS, blockieren aber Bewegung vollständig. Ideal für unsichtbare Wände:

🚧 Barriere-Blöcke platzieren
# Einzelnen Barriere-Block setzen /setblock ~ ~ ~ barrier # Linie aus Barriere-Blöcken (Breite 1, Länge 20) /fill 0 65 -10 0 70 10 barrier # Komplette unsichtbare Box um eine Zone /fill 30 64 -15 70 80 15 barrier 0 outline # Barrieren sichtbar machen (nur für Worldbuilder/OP) # Barrieren erscheinen als rote Blöcke mit X im Kreativ-Modus

🚫 Befehlssperren

🔒 SuS-Berechtigungen einschränken
# SuS können keine Blöcke in Zone 1 abbauen /gamemode adventure @a[tag=!lehrer] # Fliegen für alle SuS deaktivieren /ability @a[tag=!lehrer] mayfly false # Bauen/Abbauen für alle SuS deaktivieren /ability @a[tag=!lehrer] mute false # SuS können keine Befehle nutzen /ability @a[tag=!lehrer] operator false

🗺️ Weltgrenze setzen

🌍 Weltbegrenzung
# Weltgrenze auf 200 Blöcke Radius setzen /worldborder set 200 # Warngrenze anzeigen (ab 50 Blöcke vor Grenze) /worldborder warning distance 50
🚨
Sicherheits-Checkliste vor dem Unterricht: Teste die Welt als normaler SuS (deop dich selbst temporär). Versuche aktiv, Bereiche zu erreichen, die gesperrt sein sollten. Finde Lücken, bevor es die SuS tun.
8 🧩

Strukturblöcke für wiederverwendbare Module

Strukturblöcke (Structure Blocks) erlauben dir, Gebäude zu speichern und beliebig oft einzufügen. Perfekt für Quiz-Räume, Aufgaben-Stationen und Klassenzimmer-Templates.

🔧 Strukturblock aktivieren

🧱 Strukturblock in der Hand
# Strukturblock erhalten (nur im Kreativ-Modus) /give @s structure_block # Oder per Befehl direkt setzen /setblock ~ ~ ~ structure_block

💾 Struktur speichern und laden

1

Struktur speichern

Platziere Strukturblock → Modus „Speichern" → Namen vergeben (z.B. quiz_raum_1) → Größe einstellen → Exportieren klicken.

2

Struktur laden

Neuen Strukturblock → Modus „Laden" → Namen eingeben → „Laden" → Struktur erscheint als Vorschau → Bestätigen.

3

Per Befehl laden (automatisch)

Für automatisches Laden per Command Block: /structure load quiz_raum_1 ~ ~ ~

📦 Struktur per Befehl laden
# Struktur an bestimmter Position laden /structure load quiz_raum_1 40 65 20 # Struktur mit Rotation laden /structure load aufgaben_station 80 65 0 0_degrees none false true # Struktur löschen (für Reset) /structure delete quiz_raum_1

📁 Empfohlene Struktur-Bibliothek

🏠 Basis-Module

  • spawn_halle – Einstiegsbereich
  • npc_station – Aufgaben-Station
  • quiz_raum – Multiple-Choice-Raum

🎓 Lern-Module

  • lernzone_basis – Leeres Modul
  • laboraufbau – Experiment-Setup
  • bauprojekt – Anwendungszone

⚙️ Technik-Module

  • scoreboard_init – CB-Block-Setup
  • tuer_system – Tür-Mechanik

Best Practices für den Unterricht

👩‍🏫 Klassenmanagement

✅ Vor der Stunde

  • Welt auf Reset-Stand bringen
  • Alle Scoreboards auf 0 setzen
  • Test-Durchlauf als Member machen
  • Backup der Welt anlegen

📋 Während der Stunde

  • Scoreboard-Übersicht im Blick
  • Fortschritt einzelner SuS prüfen
  • Bei Problemen: /tp nutzen
  • Chat-Log beobachten

📊 Nach der Stunde

  • Scoreboard-Screenshot machen
  • Welt als Backup speichern
  • Feedback der SuS notieren
  • Schwachstellen dokumentieren

📡 Lehrkraft-Werkzeuge

🛠️ Nützliche Befehle für die Lehrkraft
# Alle SuS zu mir teleportieren (Sammeln) /tp @a @s # Spieler einfrieren (für Erklärungsphasen) /effect @a slowness 60 255 true # Einfrieren aufheben /effect @a clear # Alle Scoreboards zurücksetzen /scoreboard players set @a Fortschritt 0 /scoreboard players set @a Aufgaben 0 # Spawnpunkt aller auf Startpunkt /spawnpoint @a 0 65 0 # Alle zu Spawnpunkt /tp @a 0 65 0

🔐 Datenschutz & Sicherheit

⚠️
Wichtige Hinweise:
  • Keine echten Namen der SuS als Scoreboard-Anzeigenamen verwenden
  • Kein Chat-Logging ohne Einwilligung der Eltern
  • Welten mit SuS-Daten nicht öffentlich teilen
  • Passwortschutz für Lehrkraft-Serverwelten aktivieren

♿ Barrierefreiheit

🌈 Inklusionshinweise

  • Immer Schrift-Schilder UND NPC-Dialoge kombinieren (Leseschwäche)
  • Farbcodes NICHT als einziges Unterscheidungsmerkmal nutzen (Farbenblindheit)
  • Klare, kurze Anweisungen — kein langer Fließtext in der Welt
  • Tastaturzugängliche Wege (keine Parkour-Pflicht-Passagen)
  • Zeitlimits bei Quizzen großzügig setzen oder deaktivieren

Export der Welt als .mcworld-Datei

Der Export als .mcworld erlaubt die Weitergabe und Nutzung auf anderen Geräten — ideal für Klassen, die mit eigenen Tablets oder PCs arbeiten.

📤 Export-Schritte (iOS/Android/Windows)

1

Welt verlassen

Verlasse die Welt und gehe zum Hauptmenü. Wähle „Spielen" → Welt-Liste.

2

Bearbeiten-Menü öffnen

Klicke auf den Stift (✏️) neben deiner Welt → „Welt exportieren".

3

Datei speichern

Wähle Speicherort. Die Datei erhält die Endung .mcworld (ca. 1–50 MB je nach Weltgröße).

4

Verteilen

Teile die Datei per Teams, Moodle, Google Classroom, USB oder QR-Code. SuS öffnen die Datei → automatischer Import in Minecraft Education.

🖥️ Export unter Windows (Dateipfad)

📁 Weltdateien finden (Windows)
# Minecraft Education Weltordner: %LOCALAPPDATA%\Packages\Microsoft.MinecraftEducationEdition_8wekyb3d8bbwe\ LocalState\games\com.mojang\minecraftWorlds\ # Ordner-Inhalt der Welt kopieren und umbenennen: MeineWelt\ ├── level.dat ← Welteinstellungen ├── level.dat_old ├── db\ ← Chunk-Daten └── world_icon.jpeg ← Vorschaubild # Ordner zippen und in .mcworld umbenennen!

✅ Checkliste vor dem Export

📋 Export-Checkliste

  • ☐ Alle Scoreboards auf 0 zurückgesetzt
  • ☐ Alle SuS aus der Welt entfernt
  • ☐ Testdurchlauf als neuer Spieler gemacht
  • ☐ Alle Türen sind geschlossen (Ausgangszustand)
  • ☐ Spawnpunkt korrekt gesetzt (0, 65, 0)
  • ☐ Weltname sprechend (z.B. Klasse5_Aggregatzustaende_v2)
  • ☐ Backup der originalen Welt vorhanden
  • ☐ .mcworld-Datei auf einem Test-Gerät importiert
💡
Versionierung: Bennene Exporte mit Datum: Lernwelt_Physik_2024-03-15_v1.mcworld. So kannst du immer auf eine funktionierende Version zurückgreifen.
